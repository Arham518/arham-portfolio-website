Harmony Premium Music

Music AppLanding PageReact.js

Problem Statement

Music platforms often feel cluttered. The challenge was creating a clean, distraction-free browser-based music player that loads local MP3 files without requiring accounts or streaming subscriptions.

Solution & Approach

Designed a minimalist, premium UI centered around playback controls and album art. Features drag-and-drop loading, playlist management, and a "Recently Played" section — all in a responsive single-page app.

Key Features

  • Drag-and-drop MP3 loading & playlist management
  • Smooth playback controls with progress tracking
  • Premium dark theme with album-art-driven visual
  • Fully responsive across mobile and desktop

Tech Stack

React.jsTailwind CSSJavaScriptNetlify

Lessons Learned

This project reinforced the value of design restraint — using negative space and typography hierarchy to guide the user's eye rather than relying on decorative elements.

RE Touch ID — Fingerprint Enhancement

Forensics ToolImage ProcessingReact.js

Problem Statement

Fingerprint analysis tools are expensive or inaccessible. The goal was a web-based tool making basic fingerprint enhancement accessible directly in the browser.

Solution & Approach

Built a React interface for fingerprint image upload, processing, and enhancement visualization. Focused on an intuitive user journey from raw upload to enhanced output display.

Key Features

  • Drag-and-drop image upload interface
  • Real-time enhancement visualization
  • Before/after comparison view
  • Processing controls and parameters

Tech Stack

React.jsJavaScriptCanvas APINetlify

Architecture

Used React component composition to separate upload, processing, and display concerns. Image processing logic is isolated in utility functions, keeping components focused and reusable.
